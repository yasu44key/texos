## F. 「選択範囲をコピー」（メディアのミニ編集・将来アイデア）

2026-06-19 ユーザー記録。G6 の画像コピー（CF_DIB を独立コマンド化）を起点に、メディアの
**部分コピー＝ミニ編集**へ発展させる構想。

- **画像**: カード上で**矩形選択**した領域だけをクリップボードへ（トリミング相当）。
- **動画**: **範囲（時間区間）**を選択してコピー（クリップ切り出し相当）。
- **音声**: **範囲**を選択してコピー。
- 起点が独立コマンド（`copy_image_to_clipboard`）なので、`copy_*_range` 系として素直に拡張できる。
- 位置づけ: TexoS が「閲覧＋持ち出し」から「軽い加工」へ一歩踏み出す入口。フィルタ（変換）／
  プロセスコントロール（外部ツール）とも棲み分く——こちらは**カード内 UI での直接編集**の系統。
- 優先度: 将来（UI・オートメーションが固まった後）。まず画像の矩形トリミングが手頃な第一歩。

詳細な計画は `docs/バージョンアップ計画.md`、設計の練り込みは
`docs/オートメーション設計メモ.md` ／ `docs/ウィジェット設計メモ.md` を参照。
