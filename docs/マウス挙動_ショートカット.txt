【整合性レビューと解決 / Claude 2026-06-18】
========================================
3分類（LMB=実行 / Shift=移動 / Ctrl=選択）は一貫していて良い。特に Shift=移動 に
統一したことで、図形の Shift+ドラッグ（図形単独移動）がカードの Shift+ドラッグ（単体移動）
と同じ意味になり、以前の衝突が自然に解消した。以下、抜けていた点を埋める。

[G1] 単一クリック選択を明文化（必須・今回の動機）
  - カード/コメントを素クリック（ドラッグなし）= そのオブジェクトのみ選択（他は解除）。
  - 既に複数選択の1枚を素クリック = その1枚に絞る（コラプス）。ドラッグなら従来どおり群移動。
  - ※これが無いと「クリックでそのカードだけ選択」という当初の狙いが満たせない。

[G2] 図形の選択を新分類へ（Phase 2 実装済み 2026-06-19）
  - Ctrl+クリック図形 = 多重選択にトグル（旧 Shift+クリックから移管）。
  - 素クリック図形 = 図形＋中のカード/コメントを選択（維持）。素ドラッグ = 図形＋中身を移動（維持）。
  - Shift+ドラッグ図形 = 図形だけ移動（維持＝Shift=移動）。Shift+クリック（動かさず）は廃止。
  - App の多重移動は selectedShapes を見るので Ctrl 移管だけで成立（handleShapeDragCards 無変更）。

[G3] 空キャンバスのドラッグ（分類どおりに入れ替え）
  - 素 LMB ドラッグ = 範囲選択（置換）／ Ctrl+LMB ドラッグ = 範囲トグル ／
    Shift+LMB ドラッグ = パン。※現行の「Shift=範囲追加」は廃止し Ctrl 側へ移す。

[G4] Alt+LMB パンは廃止（ALT 未実装の方針に合わせる。パンは Shift+空ドラッグ と 中ボタン）。

[G5] カーソルは終始 矢印（default）のまま（2026-06-19 ユーザー決定・シンプル優先）。
  ホバーでも手のひらにしない（各カード/コメント/図形の cursor:grab を default に変更済み）。
  当初は「ドラッグ開始後に手のひら」を狙ったが、要素側 cursor:default が document.body の
  grabbing を上書きするため実質ずっと矢印になる。この挙動で確定。
  ※実装に残る document.body.style.cursor="grabbing"（ObjectCard/NoteCard/Canvas/App の
    group move）はデッドコード。リファクタ時に整理する。

[G6] 画像の Ctrl+C（別件・mouse とは独立レーン）
  - 提案どおり明示メニュー「クリップボードに画像をコピー」を画像カードに追加（CF_DIB）。
    Ctrl+C は従来どおりファイルコピー（CF_HDROP）。自動 DIB 併置を残すかは後で相談。
  - これは v1.3.8 の CF_DIB の使い勝手調整。マウスモデルの Phase とは別に扱う。
