## 1. 現状の総括

開発方針（[[feedback-texos-dev-style]]）どおり、**実験リビジョンを 1.3.x で細かく刻み**、
使いながらバグを取ってきた。1.3.3〜1.3.11 で積み上がった機能群は実機で要件を満たすことを
確認済み。次は **これらをまとめて「安定版 v1.4.0」として確定する**段階に入る。

### v1.3.x で積み上げた主な機能（安定版ロールアップ対象）

- **オートフロー（v1.3.3〜）**: フィルタカード＝UNIXパイプラインのGUI再来。内蔵フィルタ
  （grep/置換/画像リサイズ・変換）＋外部プログラムフィルタ（{in}/{out}・連番・ドロップ
  ポイント・自己拡張ループ）。
- **クリップボード双方向（v1.3.4/1.3.8）**: CF_HDROP（ファイル持ち出し）＋CF_DIB（画像）。
- **用語統一・メニュー再編（v1.3.4〜1.3.7）**: 実身/仮身に統一、ツールチップ、テーマ追従、
  マウスモデル刷新。
- **窓モデル（v1.3.9/1.3.10）**: 仮身は相手の実身カードを ID（window_of）で指す。内部/外部
  2レーン分離、重複実身防止、TexoS内リネーム、実体喪失の再リンク。
- **アイデアメモ6-23（v1.3.11、A・C・B・D・E）**: ビルトインフィルタ階層化／並び維持の格子
  整列／借用元プロジェクトを開く／内部D&D=実身・新規ファイル重複バグ根治／新規ファイル作成／
  フォルダ切れ薄赤＋リンク張り直し／オフィスのインラインプレビュー（docx=mammoth・
  表計算=SheetJS・pptx等=LibreOffice→PDF）／音声・動画の簡易編集（ffmpeg）。
- **ランチャー＆フィルタ拡充（v1.3.11）**: ランチャーカード（GUI/cmd/PowerShell・{in}・保存→
  新実身・インストール済みアプリ選択・ランチャーライブラリ）／対話シェルフィルタ（一行目
  設定可・{in}）／フィルタの制限時間 0=無制限（開発者モード）。

## 3. v1.4.0 までにやること（やり残し）

### 3.1 小バグ・UI 仕上げ（`docs/UIの気づき2.txt`・最優先で次の刻み）
- [ ] **フィルタの表示名がカード外になり表示されない**（UIの気づき2 ①）。
- [ ] **表示名変更の操作統一**（UIの気づき2 ②）: 一般カードのタイトルのダブルクリックは
      仮身=表示名変更／実身=実ファイルリネーム で挙動が割れ、混乱する。**両方とも「表示名の
      変更」に統一**し、実ファイル改名は右クリックメニュー「実ファイル名の変更」に集約する。
- [ ] **テキスト仮身作成時の拡張子保全**（UIの気づき2 ③）: `.docx` の仮身を作るとテキスト
      アイコン・テキスト誤認になる。仮身作成・実ファイル名変更の際に**元の実身の拡張子（属性）
      を保全**し、ユーザーが拡張子を省いても正しい拡張子になるようにする。

## 4. 今後の課題（v1.4.0 の後）

### v1.5 系 — オートメーション本線（★次の主役。設計: `docs/オートメーション設計メモ.md`）
- **プロセスコントロールカード（#2 フル版）**: v1.3.11 のランチャーが素地。**exit code に
  よる制御フロー（分岐）**で、キャンバスがビジュアルなシェル/Makefile/CI に。Stop 常設＋
  「実行中プロセス」一覧パネル（detached でもハンドルを失わない）。常駐・対話プロセスは後送り。
- **ビジュアルコマンド**: 図形＝スコープ＋プロセスコントロール＝領域内カードへ空間的 foreach。
- **stdin/stdout カード・プログラムのフィルタ化・フィルタライブラリ強化**（この系列に吸収）。

### V2.0 — 大型課題（`docs/V2.0課題.md`）
- **AI／MCP 受け入れ口**（UI とシステムが固まってから。基盤が先・AI が後）。
- **プロジェクト間データ共有（#6/#7 Pic Up / Drop On）**: まずクリップボードで仮身を借用
  する安価な経路から。OLE ピックアップ本実装はここ。サブプロジェクト本実装も。
- **カードのグループ化／コンテナ**、**キャンバス内ウィジェット**（Wasm/サンドボックス）、
  **Wasm コーデック編集子の公開 API**。

## 5. リリース手順（毎回共通・再掲）

1. dev 停止 → `npx tsc --noEmit` → `cargo check` / `cargo test`
2. バージョン3か所更新: `package.json` / `src-tauri/tauri.conf.json` / `src-tauri/Cargo.toml`
3. `npm run tauri build` → `src-tauri/target/release/bundle/nsis/texos_x.y.z_x64-setup.exe`
4. インストーラーを `I:\` へコピー、`docs/更新履歴.md` に追記
5. デスクトップショートカット `F:\Desktop\TexoS.lnk` は release exe を指すので再ビルドで自動追従
