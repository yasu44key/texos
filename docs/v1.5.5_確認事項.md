## 4. WS-M への引き継ぎ確認点

- **入口**: `docs/v1.5_実装指示書.md` WS-M M1（図形ロック＋モジュール化＋IN/OUT カード）。
  正本 = 共有とモジュール設計.md §8〜§10。
- **要修正（M1 で必ず）**: `objects.rs` create_relation の req 分岐 — 現在は「op カードに触れる
  矢印は全部 req」。**op:"in"/"out" は透過ノード（flow を張る）なので分岐の精密化が必要**
  （実装箇所にコメント済み）。

  スケジューラは "timer"/"watch" のみ発火するので追加対応不要（確認済み）。
  ops.rs parse_op_spec に "in"/"out" の受理を追加すること。
- **§6.2 の残項目（B では未実装・M で実装）**:

  固定名レポートは同名ラベルの終端同士で上書き衝突（「固定名上書き」設計の帰結・仕様）。
