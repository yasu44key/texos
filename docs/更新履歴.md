## v1.3.2（2026-06-12）UNDO/REDOと一括操作

**テーマ: 操作の取り消し・やり直しの完全対応とUIブラッシュアップ（アイデアメモ２）**

### UNDO / REDO
- UI全体のUNDO（Ctrl+Z）/ REDO（Ctrl+Shift+Z・Ctrl+Y）を実装
  - 対象: 作成（配置・貼り付け・コメント・図形・矢印リンク）、移動（単体・グループ・図形連動）、
    変形（図形の拡縮・回転、コメントの幅）、スタイル（図形の色・濃さ、コメントの見出し/太字）、
    整列、自動レイアウト、削除 — 操作手順どおり時系列に往復できる
  - 1回のマウス操作（図形＋上のカードの移動など）は1回のCtrl+Zでまとめて戻る
  - 履歴は操作レコードとしてプロジェクトDB（.texos/texos.db）に保存。
    プロジェクト切り替え・再起動後も続きから戻せる（プロジェクトごとに独立、上限100操作）
- 削除の「復活の呪文」: 削除はソフトデリート化（deleted_at方式）
  - カード・コメント・図形・矢印リンクすべて、Ctrl+Zで矢印や実身状態ごと完全復活
  - コミット済み実ファイルは削除時に .texos/trash/ へ退避し、復活時に書き戻す
    （復活先に同名ファイルができていたら「名前 (2)」形式で衝突回避）
  - 物理削除（行・trashの掃除）は将来の「データの正規化」メンテナンスツールの仕事

### 複数選択と一括操作
- Ctrl+クリックでカード・コメントを選択に個別追加／解除（トグル）
- 選択カードへの一括操作: 「まとめて実身化（コミット）」「まとめて仮身化（コミット取り消し）」
  「まとめて削除」（対象件数表示・確認ダイアログつき、まとめて削除も1回のCtrl+Zで全復活）
- 選択カードの整列: 横一列／縦一列／格子状／横方向に均等配置／縦方向に均等配置

### 図形の操作強化
- Shift+ドラッグ＝図形の単独移動（上のカードは置いていく）
- Shift+クリック＝図形の複数選択（まとめて移動、上のカードも一緒に動く）
- 図形の階層化: 前面に重なっている図形（中心が乗っていて手前）は親図形に従って移動（推移的）
- 「図形の拡縮」メニュー: 上のカードを含む大きさにフィット／拡大1.25倍／縮小0.8倍
  （ハンドルがカードの下に隠れて掴めない問題への対策。中心固定）

### その他
- カンバス左下にバージョン表示（tauri.conf.json のバージョンに自動追従）
- バグ修正: 矢印リンクの重複作成時に無関係な行のIDが返っていた問題

## v1.3.1（2026-06-12）窓の鮮度とコメントの一級市民化

v1.3.0 実機確認のレビュー反映。

- 閲覧時にCASスナップショットを自動更新（refresh_origin_snapshot）
  - 元ファイルが消えても「最後に見た状態」が薄赤で残る。CASは不変のまま
    （新内容＝新ハッシュ＝新実身、同じ窓の仮身を一括付け替え）
  - force再コミット＝「最後のスナップショット（≒コミット時点）へ戻る」に意味が進化
- 薄赤カードの復活コマンド: 右クリック「取り込み時点の内容を復活（コミットして表示）」
- テキスト貼り付け＝画像と同格: Ctrl+VのテキストはCASに.txt実身→仮身カード
  （ラベル＝先頭行。コミットでファイル化。URLは従来どおりURLカード）
- コメント（付箋）の一級市民化:
  - 矢印リンクの対象に（付箋⇔カード、付箋⇔付箋）
  - 図形グループ・矩形選択・まとめ移動・選択範囲フォーカスに参加
- テキスト編集パネルの横幅を右端ドラッグで変更（panel_w に永続化）
- 付箋の矢印起点ズレ修正（文字数推定→ResizeObserver実測値）

## v1.2.0（2026-06-11）キャンバス操作の充実

## v1.0 〜 v1.0.2（2026-06-09〜10）ファーストリリース

構想から3日。「アイデアをデータの関係性で表現する」コンセプトの土台。

- 実身／仮身モデルとCAS（内容アドレス・不変ストレージ）— リソースを傷つけない設計
- プロジェクト＝普通のWindowsフォルダ（.texosに台帳）。内包・分岐フォーク・相互リンク・行き来
- 無限キャンバス（パン・ズーム）、ファイルD&D取り込み、矢印リンクで関係性を表現
- キャンバス内テキスト編集・画像プレビュー・音声再生
- コミットモデル: 仮身→実身化で実ファイル生成、編集破棄して再コミット（タイムマシン）、
  コミット取り消し（仮身に戻す）
- 付箋コメント、URLリンクカード、作業状態（パン・ズーム・展開状態）の永続化
- 単体exe＋インストーラー（NSIS/MSI）

技術スタック: Tauri 2 + React 19 / TypeScript + Rust / SQLite
