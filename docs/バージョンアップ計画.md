## v1.4 — オートフローMVP（V1.3後半 フェーズ1）★次の本命

`docs/V1.3後半_オートフロー設計.md` の「★確定方針」に基づく。
UNIX CUI テキストフィルタパイプラインのGUI再来 — TexoSのキラー機能候補。

- フロー矢印: フィルタカードへの接続で自動判定（relations kind='flow'）
- フィルタカード: filter_ref JSON で定義
- 接続時のMIME型チェック（不一致は赤矢印で警告）
- 実行は手動「フローを実行」から（自動実行は次フェーズ）
- 内蔵フィルタ: テキスト grep・置換、画像リサイズ・形式変換
- 外部コマンド呼び出しの逃げ道を用意
- 方針: 小さく始めて拡張。フィルタの不足はOSS公開後にコミュニティへ期待

## メンテナンスリリース（v1.4.x のどこかで）

アイデアメモ２「技術関連」の宿題。v1.3.2 のソフトデリート導入で前提が整った。
**順序（2026-06-12 決定）: 付箋のカード統一移行（`docs/カード統一モデル検討結果.md`）を
先に行い、正規化ツールはその後に作る**（旧付箋データの強制削除も正規化ツールの守備範囲）。

2. **削除データのブラウズ・復元GUI** — 復活の呪文（Ctrl+Z）の射程外になった
   過去の削除をCAS/trashから一覧・復元。「ゴミ箱を開く」的なUI
3. **テンポラリフォルダ位置の整理** — Windows作法（%APPDATA%）か
   マルチプラットフォーム志向（.texos内）かの決定
4. **UNDOの残課題** — テキスト・属性系（表示名・コメント本文・メモ・URL・図形名）、
   重なり順の記録。必要になったら追加（基盤は対応済み）

## リリース手順（毎回共通）

1. dev停止 → `npx tsc --noEmit` → 必要なら `cargo check` / `cargo test`
2. バージョン3か所更新: package.json / src-tauri/tauri.conf.json / src-tauri/Cargo.toml
   （カンバス左下の表示は tauri.conf.json に自動追従）
3. `npm run tauri build` → `src-tauri/target/release/bundle/nsis/texos_x.y.z_x64-setup.exe`
4. インストーラーを `I:\` へコピー
5. `docs/更新履歴.md` に追記
