## 実機確認チェックリスト（未実施）

### A. メニュー/整列
- [ ] 空き右クリック→「フィルタカードを追加 → ビルトインフィルタ ...」に grep/置換/リサイズ/形式変換
- [ ] バラバラに置いたカードを複数選択→「格子状に整列」で、現在の段・列の並びを保ったまま等間隔の格子に揃う
- [ ] 外部から借用した仮身の右クリック→「借用元のプロジェクトを開く」。
      借用元が TexoS プロジェクト内→そのプロジェクトに切替／プロジェクト外→借用元フォルダが開く

### C. 取り込み=実身判定
- [ ] プロジェクトフォルダ内にエクスプローラで作った未登録ファイルを**ドロップ**→**実身**（グレー＋緑、配置と同じ）になる
- [ ] プロジェクト**外**のファイルをドロップ→従来どおり仮身（琥珀）
- [ ] リンク矢印→空き→「新規ファイルを作成...」を**複数回**→それぞれ独立した実身（2枚目が1枚目の仮身にならない）
- [ ] 同じ実体を指す実身が2枚ある異常データで、片方を削除→もう片方の実ファイルは消えない（カードのみ削除）

### B. 新規ファイル作成
- [ ] 空き右クリック「新規ファイルを作成...」→名前（例 メモ.txt）→プロジェクト直下に実ファイル＋実身カード
- [ ] 同じ名前でもう一度作成→「メモ (2).txt」等の一意名になる
- [ ] 作った .txt をダブルクリック→キャンバスで編集できる／.blend 等は OS 既定アプリで開く

### D. シグナル/プレビュー
- [ ] リンクフォルダカードの参照先フォルダをエクスプローラで移動/削除→カードのドットが**薄赤**になる
- [ ] .docx をダブルクリック→キャンバスに整形プレビュー（mammoth）。閉じる/再ダブルクリックでトグル
- [ ] .xlsx / .csv をダブルクリック→キャンバスに表プレビュー（SheetJS）
- [ ] プレビューはカードと一緒に動く・読取専用（実身化しない）。失敗時は「一時的に閲覧」案内

### E. メディア編集（要 ffmpeg を .texos\filters か PATH）
- [ ] ビルトインフィルタ→「音声: 長さでクリップ...」→開始/長さ→音声カードを繋いで▶実行→クリップ結果
- [ ] 「音声: ノーマライズ」→音声を繋いで実行→loudnorm 済み
- [ ] 「動画: 長さでクリップ...」→動画を繋いで実行→指定区間が -c copy で切り出される（高速・最小容量）
